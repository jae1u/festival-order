# 🍽️ 식당 테이블 주문 시스템 (Table Order System)

도커(Docker) 기반으로 동작하는 웹 기반 식당 테이블 주문 및 주방 관리 시스템입니다.
리버스 프록시인 **Caddy**를 통해 도메인 연결 시 자동으로 HTTPS(SSL)를 지원하며, 데이터베이스 락(Lock)을 활용한 동시성 제어 기술이 적용되어 있습니다.

## ✨ 주요 기능

* **고객 주문 (Customer):** QR/링크를 통한 테이블 접속, 장바구니 담기(세션 유지), 품절 메뉴 확인
* **주방 관리 (Kitchen):** 10초 자동 새로고침, 메뉴 조리 상태(체크박스) 관리, 비정상 주문 삭제
* **정산 관리 (Billing):** 테이블별 합산 금액 확인 및 결제(세션 종료) 처리
* **메뉴 관리 (Menus):** 관리자 페이지에서 클릭 한 번으로 실시간 품절/판매 재개 토글
* **과거 내역 (History):** 정산 완료된 아카이브 조회 및 누적 총매출 확인
* **안정성/보안:**
  * 동시에 같은 테이블 접속 시 다중 세션 생성 방지 (`GET_LOCK`)
  * 주문과 결제가 겹칠 때 발생하는 유령 주문 방지 (`FOR UPDATE`)
  * API 조작을 통한 마이너스(-) 수량 주문 해킹 방어

---

## ⚙️ 사전 요구사항

* Docker 및 Docker Compose 설치
* (운영 시) 서버 IP로 연결된 도메인 주소

## 🚀 설치 및 실행 방법

### 1. 환경변수 파일 복사 및 설정

보안 정보가 담길 `.env` 파일을 생성합니다. 프로젝트 루트 경로에서 아래 명령어를 실행하세요.

```bash
cp .env.example .env
```

생성된 `.env` 파일을 열어 아래 항목들을 수정합니다.

* `DOMAIN`: 서비스할 실제 도메인 (로컬 테스트 시 `localhost` 유지)
* `FLASK_SECRET_KEY`: 무작위 영문/숫자 조합 (세션 암호화용)
* `ADMIN_PASSWORD`: 관리자 페이지 접속 비밀번호

### 2. 데이터베이스 초기화 (선택)

`db/init.sql` 파일을 열어 식당에서 판매할 메뉴 목록, 가격, 이미지 URL을 필요에 맞게 수정할 수 있습니다. (초기 실행 시 한 번만 적용됩니다.)

### 3. 컨테이너 빌드 및 실행

아래 명령어를 통해 컨테이너들을 백그라운드에서 실행합니다.

```bash
docker compose up --build -d
```

## 💻 사용 방법

로컬 환경(`DOMAIN=localhost`) 기준이며, 실제 도메인 설정 시 해당 도메인(HTTPS)으로 자동 연결됩니다. 포트 번호(`:5000`)를 입력할 필요가 없습니다.

* **📱 손님용 페이지:** `http://localhost/` (또는 `https://본인도메인/`)
  * 테이블 번호와 이름을 입력하고 접속하여 메뉴를 주문합니다.
  
* **👨‍🍳 관리자 페이지:** `http://localhost/admin/login`
  * `.env`에 설정한 `ADMIN_PASSWORD`를 입력하여 로그인합니다.
  * 상단 네비게이션 바를 통해 주방, 정산, 메뉴 관리, 내역 탭을 이동할 수 있습니다.

---

## 🛑 서버 종료 및 초기화

서버를 중지하려면 아래 명령어를 사용합니다.

```bash
docker compose down
```

**(주의)** 기존의 테스트 주문 내역이나 설정된 DB 데이터를 완전히 초기화하고 처음부터 다시 시작하려면 `-v` 옵션을 추가하여 볼륨까지 삭제해야 합니다.

```bash
docker compose down -v
```
